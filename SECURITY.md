# Security Policy

## Supported Versions

Only the latest version of the project is supported (the current `main` branch / latest release).
Older versions do not receive security fixes — please update to the latest version before reporting a vulnerability.

| Version        | Supported          |
| -------------- | ------------------- |
| Latest (main)  | :white_check_mark: |
| Older releases | :x:                 |

## Reporting a Vulnerability

If you discover a vulnerability in **OpSec-Enhanced**, please **do not open a public issue**.

Instead, report it through **GitHub Security Advisories**:

1. Go to the [Security → Advisories](https://github.com/SU4G3/OpSec-Enhanced/security/advisories) section of the repository.
2. Click **"Report a vulnerability"**.
3. Describe the issue in as much detail as possible: reproduction steps, affected version, potential impact, and a PoC if available.

### What to expect

- **A response within 24–48 hours** of submitting your report.
- We will confirm receipt and provide an initial severity assessment.
- If the vulnerability is confirmed, we will keep you updated on remediation progress and agree on a responsible disclosure timeline.
- If the report is declined, we will explain why.

### Please

- Do not publicly disclose vulnerability details before a fix is released.
- Act in good faith — do not exploit the vulnerability to harm users or their data.

Thank you for helping keep this project secure.
